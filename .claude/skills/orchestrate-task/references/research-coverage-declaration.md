# research-coverage-declaration — 調査網羅宣言の様式

調査タスク終了時に埋める。`required` は判断表と project の `.tazuna/harness.toml::[kb]` 地図から導出する(自己申告ではない)。判断表・面の定義の詳細は `docs/design/research-routing.md` が正本(ここでは複製しない)。

```
必須面 (required):     <導出結果の列挙>
探した面 (searched):   <面: 見つけたもの / 出典>
届かなかった面 (unavailable): <面: 理由 (認証・レート・停止など)>
飛ばした面 (skipped):  <面: 理由>
出典: <引用 ID (shiron:/genten:/dsp:) と URL の列挙>
```
